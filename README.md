# Sift

My app, "Sift", helps educational professional and online learning services decide which Claude Model to use by evaluating over 4,000 prompts and responses to determine the model that produces the highest quality learning experience for users.

> A course project for **MIST 4600: Computer Programming in Business** at the University of Georgia's Terry College of Business (Fall 2026).

## Problem
My user is an educational technology platform, such as Khan Academy, Duolingo, or Quizlet, that is trying to find the best Claude model that produces answers according to word count and subject matter. The platforms provide video lessons, interactive courses, and test prep that is partially generated by Claude. The app answers which Claude model would be the smartest investment to implement into current e-learning platforms. 

## What it does
My app answers three questions:
1. **Clarity**: How clear and understandable is the short explanation provided? Can it be mapped across all grade levels? 
2. **Topic Difficulty**: After using an LLM to rank the topics by difficulty or mapping topics across grade levels, does topic difficulty influence model performance?
3. **Task Type**: Depending on the task type (explaining concepts, generating fictional narratives, etc.), which model performs best? Which task type would be most useful for the platform?

## Data
The [Name That LLM Response Data Set](https://www.kaggle.com/datasets/seyitkaangunes/ntl-extra-api-passages/data) on Kaggle, collected and updated October 2026. The dataset was published on Kaggle under CC BY 4.0. by Seyit Kaan Gunes. The dataset is a synthetic, complimentary dataset to Kaggle's "Name That LLM" competition in which participants must guess which LLM wrote it. The data contains 1000 different prompts ran on five different Claude models, producing 4,998 reponses.
